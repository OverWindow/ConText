# 하루랩 샘플의 AI 기능

홈에서 **하루랩 스타트업 샘플 열기**를 선택하면 AI 문서 작성, AI 채팅, AI 연결 설정을 사용할 수 있다.

- **AI 연결 설정**: 개인 워크스페이스에서 사용하던 계정·모델·개인 키 설정을 재사용한다. 데스크톱의 개인 키는 기존 보안 저장소에, 웹의 개인 키는 기존 서버 저장소에 보관한다. 샘플 저장소에는 키를 기록하지 않는다.
- **AI 문서 작성**: 하루랩 샘플 본문을 검색해 관련 발췌문으로 초안을 생성한다. 직접 작성, 저장, AI 수정안 검토·적용·거절, 되돌리기, 삭제를 지원한다. 데스크톱에서는 DOCX/HWPX, 웹 샘플에서는 MD/TXT로 내려받을 수 있다.
- **AI 채팅**: 샘플 본문에서 근거를 검색하고, 인용한 샘플 문서를 열 수 있다. 실패한 답변을 다시 요청할 수 있으며, 근거가 없으면 모델 호출 없이 근거 부족을 표시한다.

샘플 원본 40개를 바탕으로 이 기기의 작업 사본을 수정할 수 있다. 문서를 열어 **본문 수정**을 선택하면 제목·본문·목록·표를 편집할 수 있다. 이미지 픽셀 편집과 원본 바이너리 서식 편집은 제공하지 않는다. **캔버스 수정**에서는 파일 배치·메모·도형·연결을 수정하며 실행 취소·다시 실행을 지원한다. 현재 열어 둔 폴더도 폴더 이름이나 빈 배경을 잡아 끌면 내부 항목과 함께 이동한다. 이동 위치는 자동 정렬에 덮어쓰이지 않으며 재시작 후에도 유지된다. 새 TXT/Markdown 파일, 복사본, 이름 변경과 파일의 폴더 이동도 지원한다. 저장된 내용으로 AI가 검색한다.

**샘플 초기화**는 확인 후 샘플 파일·본문·배치·메모·연결을 처음 상태로 복원한다. 추가한 샘플 파일은 제거되지만 AI 작성 문서·대화·연결 설정은 유지된다. 기존 문서를 수정하거나 초기화하기 전의 본문은 이전 AI 인용 확인용으로 보관한다.

개인 폴더는 연결하거나 변경하지 않는다. 샘플 수정 내용과 작성한 문서·대화는 기기·브라우저의 샘플 전용 저장소에 보관되며 클라우드 동기화 대상이 아니다. 브라우저 저장소를 지우면 이 기록도 삭제된다. 다시 열 때 저장된 AI 문서는 작성 화면의 목록에서, 대화는 채팅의 **대화 기록**에서 선택한다.

샘플 AI 검색은 현재 작업 사본의 본문을 사용한다. 과거 이력의 통합 검색과 기준일별 검색은 제공하지 않으며 이미지 내용 자체는 AI 검색 대상이 아니다. 모델에는 최대 20개 발췌문, 합계 24,000자만 보낸다. AI가 반환한 출처 객체 대신 요청에 실제로 사용한 발췌문에 인용을 연결하고, 문서 구조와 출처 ID를 검증한다.

웹에서는 샘플 열람과 직접 작성은 로그인 없이 가능하다. AI 생성·연결 설정은 로그인이 필요하며, 인증이 없거나 만료돼도 작업 중인 샘플을 강제로 다른 페이지로 이동시키지 않는다. 기존 `/api/ai/connection`, `/api/ai/models`, `/api/ai/context`를 사용하므로 새 서버 API 배포는 필요하지 않다.

검증: 샘플 저장·검색·출처 검증과 편집 단위 테스트 8개, 웹 데스크톱·모바일 시나리오 10개, 데스크톱 샘플 및 기존 작성 시나리오 5개. AI 모델 호출만 합성 응답으로 대체하고 검색·저장·IPC·편집·문서 내보내기는 실제 구현으로 실행한다. 웹·데스크톱 빌드와 웹 타입 검사·린트를 확인한다.
