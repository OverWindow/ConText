# 워크스페이스 선택·파일 클릭 동작 — 2026-10-27

웹과 데스크톱은 공통 `ApplicationShell`, `FileCard`, `DocumentConversions`를 사용한다.

## 사용 방식

- 좌측 메뉴에서 워크스페이스 목록, 개별 연결 해제, 폴더 연결과 클라우드 열기를 제거했다. “나의 워크스페이스” 버튼은 독립 홈으로 이동한다.
- 선택·연결·생성은 홈에서 한다. 캔버스에는 현재 워크스페이스 하나만 표시한다. 데스크톱에서 현재 워크스페이스를 연결 해제해도 다른 워크스페이스를 자동 선택하지 않고 홈에 머문다. 앱 시작 시 마지막 작업 공간 복원은 유지한다.
- 파일에 마우스만 올리면 복사·변환 도구가 나타나지 않는다. 한 번 클릭하면 도구가 나타나며 마우스를 옮겨도 유지한다. 다른 파일이나 빈 공간을 누르면 닫힌다.
- 파일 카드를 두 번 클릭하면 미리보기가 열린다. 키보드에서는 Space로 도구를 열고 Enter로 미리보기를 연다. 연결점과 복사·변환 버튼을 누를 때는 미리보기가 열리지 않는다.
- 웹에도 데스크톱과 같은 변환 패널을 연결했다. 웹은 기존 서버 변환 API와 브라우저 다운로드를, 데스크톱은 기존 로컬 처리와 저장 대화상자를 사용한다. 이미지 등 변환 대상이 아닌 파일에는 복사만 표시한다. 읽기 전용 사용자는 수정 도구를 사용할 수 없다.

파일의 더블 클릭은 캡처 단계에서 처리해 캔버스 확대가 가로채지 않도록 했다. 빈 캔버스의 확대와 폴더·연결선·드래그 동작은 기존 구현을 사용한다. DB 테이블이나 API 경로는 추가하지 않았다.
