# 웹·데스크톱 공통 환경 진행 기록

작성·최종 점검: 2026-10-26 (한국 시간)

## 2026-10-26 수동 클라우드 동기화

- 폴더·문서·불변 버전·고정 head·메모·연결선·초안을 선택한 계정의 클라우드 작업 공간에 수동 게시한다. 준비·검증 후 원자적으로 반영하고 중단·재시작·응답 유실을 복구한다.
- 웹은 공통 중첩 폴더 배치로 마지막 완료 상태를 열고 기존 미리보기·이력·초안·검색·새 AI 채팅을 사용한다. 원본 수정은 데스크톱에서 수행한다.
- 서버 여섯 테이블과 migration 0013, SQLite 9, main 전송·IPC, 웹 scope 조회를 추가했다. 기존 자료와 변경 사항을 유지했다.
- 개발 DB 백업 후 migration 적용과 모델 일치를 확인했다. 서버 221개, 패키징 앱 기존 20개·동기화 1개, 웹·모바일 동기화 4개 검사 통과. 실제 Google 계정 동의와 실제 사용자 폴더의 클라우드 전송은 자동 수행하지 않았다.
- AWS 만료 업로드 정리는 scoped DeleteObject 권한 추가가 필요하다. 구체적 API·설정·정책·제약과 검증은 [구현 기록](cloud-sync-implementation.md)을 따른다. 아래 P0–P6의 transport 미구현 표시는 이전 단계의 기록이다.

P0–P6의 로컬 구현과 macOS Apple Silicon 검증을 마쳤다. 실제 Google OAuth와 개인 실계정, Windows 실행은 별도 검증 대상으로 남긴다. 기능별 근거·명령·제약은 [검증 기록](desktop-web-parity-verification.md), 실행은 [데스크톱 안내](../apps/desktop/README.md)를 따른다.

## 2026-10-26 데스크톱 카드 형식 변환·복사본

- 웹 변환·복사 카드 UI를 공통화하고 웹 HTTP 어댑터와 데스크톱 IPC 어댑터를 연결했다. 웹의 기존 4종과 데스크톱의 기존 HWPX를 포함한 5종 출력을 유지한다.
- 변환은 로컬 수정 이력의 정규화 자료와 번들 파서를 사용한다. 결과·경고·해시·대기 작업을 SQLite에 보관하고 카드 옆과 미리보기에서 공유한다. 저장 창 취소, 같은 결과 재사용, 재실행 복구와 실패 재시도를 지원한다.
- 일반 파일 전체의 독립된 실제 복사본을 같은 폴더에 만들고 이름 충돌을 피한다. 문서의 현재/고정 이력과 바이너리 파일을 처리하며 중복 요청·앱 중단·외부 변경을 검증한다. 중첩 폴더의 원본 근처 배치와 주변 이동 애니메이션을 재사용한다.
- SQLite 8 마이그레이션 전에 백업하며 원본·이력·배치를 유지한다. 캐시·복사 기록은 기기별이고 변환·복사는 계정과 네트워크를 요구하지 않는다. 전체 폴더 해제 시 늦은 결과가 되살아나지 않도록 한다.
- 검증 결과·최종 앱 fingerprint와 화면은 검증 기록의 변환·복사 항목에 남긴다.

## 2026-10-26 데스크톱 선택적 계정 로그인

- 폴더 연결 전후의 왼쪽 아래에 로그인/계정 관리를 추가했다. 웹과 같은 Google 계정을 시스템 브라우저 PKCE로 연결하고 `/api/me`가 검증한 웹 사용자 UUID·이메일·이름을 표시한다. 로컬 기능은 로그인을 요구하지 않는다.
- 기존 기본 ChatKHU 계정 저장소를 공유하고 이전 AI 로그인도 프로필 확인 후 이어서 사용한다. 토큰은 OS 보안 저장소로 암호화하며 일반 계정 IPC에는 전달하지 않는다. 개인 키·모델은 보존한다.
- 재실행·절전 복귀·주기적 갱신, 오프라인·만료 표시, 브라우저 연결 취소, 이 기기만 로그아웃을 처리한다. 늦게 도착한 인증 응답은 로그아웃한 계정을 복원하지 않는다.
- 사용자의 선택에 따라 로컬 API `http://127.0.0.1:8000`을 기본값으로 둔다. 앱에서 서버를 바꿀 수 있다. 현재 로컬 API와 개발·운영 웹의 인증 프로젝트 일치, Google provider 시작과 데스크톱 callback 허용을 사용자 없는 공개 취소 흐름으로 확인했다. 실제 사용자 Google 로그인 완료는 별도 확인 대상이다.
- 로그인·로그아웃·계정 변경 후에도 기존 파일·폴더 연결·배치·초안·대화는 기기에 남는다. 자동 업로드나 웹 동기화는 시작하지 않으며 후속 계정 binding 경계를 동기화 계약에 기록했다.
- 검증 결과·로그·화면·최종 앱 fingerprint는 검증 기록의 로그인 항목을 따른다.

## 2026-10-26 캔버스 제스처·모션·중첩 탐색

- 웹·데스크톱 공통 캔버스에서 트랙패드 두 손가락 스크롤은 가로·세로 이동, 핀치/Ctrl·⌘+휠은 확대·축소로 동작한다. 터치스크린의 기존 조작은 유지한다.
- AI 패널은 280ms 동안 오른쪽에서 열리고 닫힌다. 캔버스 폭도 함께 전환하고 대화·질문 초안을 보존한다. 빠른 반전과 모션 감소 설정을 처리하며 참조 카메라는 크기 전환이 끝난 뒤 한 번 맞춘다. 웹 우측 호출 아이콘을 제거하고 왼쪽 메뉴로 연결한다.
- 중첩 폴더는 누적 표시 배율에 따라 각각 펼친다. 멀리서는 이름만 표시하고 수정 상태에서도 한 번 클릭해 펼친다. 지역 배율 .42에서 열고 .34 이하에서 접는다. 클릭 목표는 .55이며 내부 축소율을 반영해 이후에도 더 확대할 수 있다. 깊은 확대 화면의 저장·재시작도 지원한다.
- 텍스트는 배치 계산에서 제외한 겹침 메모다. 새 파일·폴더는 같은 영역의 이웃만 가로로 움직인다(간격 24, 항목당 최대 160, 최대 8개). 한도를 넘으면 새 항목만 가까운 빈 공간에 둔다. 이동은 240ms이며 폴더의 자식도 함께 옮긴다. 빈 논리 폴더 기본 크기는 320×240이다.
- 새 항목 배치를 저장하고 undo/redo하며 저장 실패는 원래 배치로 보상한다. 실제 생성한 파일은 배치 실행 취소로 지우지 않는다. 기존 폴더의 자동 위치를 고정한 뒤 추가하고 초기 로드·새로고침·외부 파일 감시에 추가 애니메이션을 적용하지 않는다.
- 폴더 호버는 테두리·약한 빛과 이름 강조로 바꿨으며 박스 위치·크기는 변하지 않는다. AI 패널 전환 중에도 기존의 제한된 캔버스 항목을 유지해 주변 파일을 다시 마운트하지 않는다.

- 검증: 최종 단위·통합 55개와 패키징 앱 17개, 웹·모바일 통합 73개(트랙패드 모바일 1개 제외), 확대 보완 6개, 업로드 복구 12개, 캔버스 40개, 복사본 2개 통과. 웹 빌드·타입·린트와 앱 패키징도 통과했다. 중복 범위는 합산하지 않으며 상세 로그·화면·fingerprint는 검증 기록을 따른다.

## 2026-10-26 캔버스 정리

- 웹 논리 폴더와 데스크톱 물리 폴더에 공통 8개 상한 정책을 적용했다. 직속 파일·하위 폴더를 합산하며, 중첩 콘텐츠를 비례 축소한다. 원래 저장 좌표와 표시 좌표 사이의 역변환을 사용한다.
- 편집 시작/종료로 펼침 상태나 박스·카메라가 바뀌지 않는다. 확대해 보이던 파일을 바로 옮길 수 있고 접힌 박스는 통째로 움직인다. 웹 박스 이동은 내부 항목을 함께 저장하고 그룹 전체를 되돌린다.
- 공통 하단 도구를 하나의 가운데 정렬 행으로 합쳤다. 편집 도구는 오른쪽으로 확장하고 좁으면 행 내부에서 스크롤한다. 하단 안내 문구와 큰 파일 아이콘을 제거했다.
- 데스크톱 경로 행·화살표·우측 개수와 좌측 새 파일 버튼을 제거했다. 큰 작업 공간 제목으로 루트 전체 보기에 돌아간다. 파일명·확장자·이미지 미리보기·상태와 기존 AI 참조 동작은 유지한다.
- 검증: 단위/로컬 통합 48개, 최종 배치 10개, 패키징 앱 16개, 웹/모바일 폴더·도구 38개, 캔버스 40개, AI·검색 14개 통과. 웹 프로덕션 빌드·타입·린트·데스크톱 패키징도 통과했다. 최신 소스/패키지 fingerprint와 화면은 검증 기록에 남겼다.

## 구조와 데이터 보존

- 공통 코드는 기존 Docker/Vercel 프런트 빌드 루트를 유지하도록 `frontend/shared/{core,ui,writing,chat,canvas}`에 두었다. Next.js/Supabase/HTTP와 Electron/IPC/파일 접근은 환경별 어댑터가 담당한다.
- 시작 시점의 미커밋 문서 카드·스타일·이미지를 보존했다. 카드 변경은 별도 FileCard로 이동해 유지했으며 강제 reset/clean을 사용하지 않았다. 시작 diff는 `/private/tmp/context-parity-starting.patch`에 보관했다.
- 로컬 DB는 `user_version=7`이다. 마이그레이션 전 SQLite backup API를 사용한다. 기존 entry UUID·배치·뷰포트를 유지하고 모든 일반 파일에 별도 logical document UUID를 부여한다.
- 실제 파일의 관측 버전과 검색용 현재 버전을 분리했다. 명시적인 현재 지정은 백그라운드 색인으로 바뀌지 않는다. 수동 이력 연결은 출처를 유지한 새 스냅샷이며 원본을 교체하지 않는다.
- 파일 저장은 해시·임시 파일 fsync·원본 보존·독점 게시·journal을 사용한다. 충돌 시 원본과 편집안을 남기고 재시작 복구 화면에서 각각 저장할 수 있다.
- 연결 해제는 색인을 중단한 뒤 해당 작업 공간의 앱 자료를 트랜잭션으로 정리한다. 원본·내보낸 파일·이전 DB 백업·저장 복구 자료는 유지하며 확인 화면에 설명한다.
- outbox는 기기별 순번·revision·tombstone과 함께 metadata와 같은 트랜잭션에 저장한다. 기기별 경로·키·토큰은 제외하고 파일 관계에는 logical document ID를 쓴다. [확장 계약](local-sync-contract.md)에 실제 transport와 충돌 병합의 후속 결정을 정리했다.

## 구현 중 발견해 수정한 회귀

- 색인 갱신 후 React Flow의 측정 정보가 소실되어 재시작 시 카드가 보이지 않는 문제를 수정했다.
- 색인 진행 이벤트를 문서 전체 목록 대신 최대 10Hz의 작은 delta로 바꿨다. 변경 없는 파일은 재시작 후에도 재파싱하지 않는다.
- 원본이 삭제된 과거 인용은 저장된 스냅샷으로 열며 원본 작업을 비활성화한다. AI 참조 강조는 저장된 배치를 바꾸지 않는다.
- 연결 방향 변경을 실행 취소/다시 실행에 포함했다. 폴더 이름 변경 시 scope와 뷰포트를 새 상대 경로에 연결한다.
- 현재 날짜 검사는 한국 시간 자정을 기준으로 하고 실제로 없는 날짜·미래 날짜를 거부한다.
- 직접 ChatKHU 요청에서 불필요한 내부 문맥 필드를 제거했다. 서버·개인 연결 실패 시 자동으로 다른 계정을 사용하지 않는다.
- AI 처리 여부가 불명확하면 자동 재전송하지 않는다. 선택 요약의 파일 게시 실패는 기존 결과로 재개하며 같은 AI 요청을 다시 보내지 않는다.

## 2026-10-25 — 실제 로컬 폴더를 캔버스 영역으로 변경

- 공통 영역 선택은 parent-relative 좌표 대신 실제 캔버스 절대 좌표로 검사한다. 웹 선택/요약 4개 회귀, 타입·린트·빌드 통과. 로컬 38개·패키징 앱 9개 통과.

- 이전 뷰포트를 보존하면서 읽기 쉬운 배치용 뷰를 별도 namespace에 저장한다. 확대한 화면 좌표는 원본 파일 좌표의 제한과 분리해 카메라를 복원한다.

## 2026-10-25 — 폴더 박스 크기 유지와 실제 파일 드롭

- **캔버스 수정**을 켜도 하위 폴더의 내부 항목을 펼치지 않는다. 편집 전후 박스 크기·배치·화면 배율을 그대로 유지하며, 명시적으로 진입한 폴더의 직계 항목만 보여 준다. 마지막 작업 폴더·편집 모드·카메라를 함께 복원한다.
- 폴더 이동 손잡이를 제거했다. 박스 배경이나 중앙 대표 카드 자체를 끌어 전체 영역을 이동한다. 별도의 **안으로** 버튼 없이 편집 중 대표 카드를 두 번 누르면 내부로 진입한다. 전체 이름과 혼합 파일/폴더의 같은 대표 크기는 유지한다.

- 단위 검사는 전체 내용 크기·숨긴 내부 좌표 보존, 원래 이름 보존, 빈 파일/메모 공간 배치, 충돌과 잘못된 대상을 확인한다. 실제 패키징 앱 검사는 편집 시작/종료 전후의 실제 박스 경계·카메라 일치, 박스 배경/대표 카드 드래그, 손잡이 부재·내부 항목 숨김·드롭 강조·실제 파일 이동·실행 취소/다시 실행·충돌·재시작을 확인한다.

## 2026-10-25 — AI 대화와 문서 검색 통합

- 웹·데스크톱의 공통 AI 패널에서 대화/검색 전환을 제거했다. 한 입력으로 관련 문서를 먼저 찾고, 같은 질문과 범위로 AI 답변을 요청한다. 데스크톱의 별도 본문 검색 패널과 메뉴는 제거했다. 상단의 파일 이름 필터는 유지한다.

- 긴 소개·모드 설명·반복되는 메시지 제목을 제거했다. 새 대화·검색 설정·전송·원문 열기·접기·재시도는 아이콘이며 접근 가능한 이름과 툴팁을 유지한다. 검색 범위·기준 날짜는 설정 아이콘으로 펼친다. 색인 상태와 검색 경고도 작은 지표·아이콘으로 표시한다.
- Enter 전송·Shift+Enter 줄바꿈·한글 조합 중 Enter 처리를 구분한다. 접기/펼치기의 초안·대화 유지, 출처 강조, 기존 요청 ID 재사용과 수동 재시도를 유지한다. AI 오류 이후 원문 열기 오류가 발생해도 오류를 숨기지 않는다. 실제 유료 AI 요청의 자동 재시도는 추가하지 않았다.

최종 패키징 앱과 웹·모바일의 검사 결과·화면·fingerprint는 [검증 기록](desktop-web-parity-verification.md)에 남긴다.


## 2026-10-25 — 개별 파일 연결 해제와 다시 연결

- 미리보기와 문서 관리의 파일 행에 연결 해제 아이콘을 추가했다. 연결 해제는 원본 파일을 옮기거나 삭제하지 않으며, 문서 버전·기존 대화·배치·연결선 자료를 보존한다. 폴더 설정의 작업 공간 전체 해제와 구분한다.
- 해제된 파일은 캔버스·일반 문서 목록·현재/과거/기준일 검색·새 AI 문서 검색·작성의 자동 문서 수집·버전 후보에서 제외한다. 기존 대화의 인용 스냅샷은 열 수 있으며, 연결 해제 상태를 표시하고 원본 작업을 비활성화한다.
- 연결 상태는 작업 공간/entry ID별 로컬 설정으로 저장한다. 스캔·파일 감시·재시작이나 외부 이름 변경으로 자동 재연결하지 않는다. 문서 관리의 해제 목록에서 다시 연결하면 같은 ID·배치·이력·연결선을 복원한다. 디스크에서 사라진 파일의 재연결 버튼은 비활성화한다.
- 파일 처리 도중 해제된 경우 파싱 결과를 새 버전·검색 색인에 등록하기 전에 연결 상태를 다시 확인한다. 다른 파일의 처리는 유지한다. 전체 작업 공간을 해제하면 파일별 설정도 정리한다. DB 버전 7을 유지하며 기존 저장소를 초기화하지 않는다.

전체 로컬 검사 44개와 최종 패키징 앱 13개 E2E가 통과했다. 실행 파일의 fingerprint와 재현 명령은 [검증 기록](desktop-web-parity-verification.md)에 갱신했다.


## 2026-10-25 — 내 컴퓨터의 연결 폴더 전체 해제

- 사용자 의도에 맞춰 왼쪽 **내 컴퓨터**에 연결된 폴더마다 전체 해제 아이콘을 표시한다. 폴더 설정 안의 기존 전체 해제 동작을 같은 핸들러로 연결하며, 파일별 해제와 구분한다.
- 전체 해제 확인은 정확한 대상 폴더 이름과 앱 자료 정리 범위를 표시한다. 원본 폴더와 모든 하위 파일은 보존한다. 취소하면 연결과 현재 작업이 유지된다.
- 열지 않은 다른 연결 폴더를 해제해도 현재 캔버스·채팅 초안은 유지한다. 현재 폴더 해제 전 캔버스 저장을 완료하고, 삭제된 작업 공간의 오래된 저장 콜백을 분리한 뒤 남은 폴더로 이동한다. 마지막 폴더 해제 시 열린 화면을 정리하고 시작 화면으로 돌아간다.
- 폴더 이름은 줄바꿈해 읽을 수 있고 경로는 한 줄로 표시하며 전체 경로를 툴팁에 유지한다. 실제 앱 검사에 취소·다른 폴더 해제·현재 폴더 해제 후 이동·마지막 해제·재시작·원본 및 중첩 원본 보존을 포함한다.

폴더 전체 해제의 새 검사는 개발 앱과 최종 실행 파일에서 통과했다. 최종 앱 전체 실행의 기존 폴더 탐색 1개 실패와 재검사 결과는 검증 기록에 구분해 남겼다.


## 2026-10-25 — 참조 더 보기와 기존 캔버스를 유지하는 확대

- 공통 AI 패널의 참조 목록을 기본 접힘으로 표시한다. 답변 아래 화살표로 순서대로 펼치고 다시 접으며, 인용 번호를 누르면 목록과 해당 발췌를 함께 펼친다. 마우스·키보드·접근 가능한 이름을 제공한다. 검색/AI 연결 경고는 접힌 목록 밖에서도 확인할 수 있다.
- 데스크톱의 참조 전용 파일 필터·임시 평면 배치를 제거했다. 기존 파일·물리 폴더·메모·연결선과 좌표/크기를 유지하면서 참조 파일의 기존 공간 좌표로 카메라만 이동한다. 상단 오버레이 높이를 반영하고, 출처 목록 펼침/접힘이나 메시지 폴링으로 다시 초점을 옮기지 않는다.
- 참조 카메라를 저장된 화면에 덮어쓰지 않는다. 참조 종료는 확대 전 화면으로 복원하고, 명시적으로 다른 폴더로 이동할 때는 새 목적지를 우선한다. 폴더 안에서도 주변 파일·메모와 폴더 박스의 기하를 유지한다.
- 표시 한도 밖의 인용은 기존 항목을 빼지 않고 필요한 파일·조상 폴더를 임시로 추가한다. 이미 보이던 배치·카드 크기는 유지하며 원본 entry/좌표를 수정하지 않는다. 기존 폴더의 좌표계와 일반 파일의 200×290/혼합 카드 크기를 유지한다.
- 로컬 전체 46개, 실제 최종 앱 전체 15개, 웹/모바일 14개가 통과했다. 전체 결과·새 화면·실행 파일 fingerprint는 검증 기록을 따른다.
