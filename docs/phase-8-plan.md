# Phase 8 — Format Conversion

- PDF·DOCX·HWPX·TXT·Markdown의 기존 NormalizedDocument를 공통 입력으로 사용해 PDF·DOCX·TXT·Markdown을 내보낸다. 원본과 버전 이력은 변경하지 않는다.
- 제목·문단·목록·표·코드를 문서 순서대로 보존한다. PDF에는 한글 폰트를 포함하고 긴 문단·표를 페이지에 나눈다. 이미지·병합 셀·정밀한 원본 서식·OCR·HWP 출력은 범위 밖이다.
- 버전/형식당 하나의 변환 작업을 DB에 기록하고 중복 요청은 재사용한다. Celery와 DB outbox를 사용하며 실패·브로커 장애·작업자 중단을 복구한다. 오래된 작업자는 새 결과를 덮어쓸 수 없다.
- 변환 결과를 해당 버전의 converted/ 아래 S3에 암호화 저장한다. 목록과 다운로드 모두 현재 워크스페이스 접근 권한을 확인한다. VIEWER도 읽기 파생물 생성과 다운로드를 허용한다.
- 미리보기의 내보내기 탭에서 형식 선택·진행·재시도·다운로드를 제공한다. 과거 버전도 선택하여 변환할 수 있다.
- DB 백업 후 마이그레이션을 적용하고, 격리 DB/S3 테스트·브라우저 테스트·한글 PDF 렌더링·실제 저장소 변환/다운로드를 검증한다.
