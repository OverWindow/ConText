# Phase 5 구현 계획

- 기존 Document/DocumentVersion, 검증된 S3 원본과 비동기 파싱, 한국어 중앙 미리보기를 유지한다.
- 버전별 업로드 request ID, 등록 메모, 수동 연결 원본 버전 ID를 추가한다. 문서 행 잠금으로 버전 번호를 할당하며 동시 요청/중복 재시도를 제어한다.
- 기존 문서에 파일을 새 버전으로 올릴 수 있다. 업로드 완료는 최초 현재 버전만 자동 지정한다. 이후 현재 버전은 OWNER/EDITOR가 명시적으로 선택한다.
- 같은 워크스페이스의 검증된 버전을 수동 연결할 수 있다. 원래 문서는 유지하고 새 버전 메타데이터가 불변 원본 S3 객체를 참조한다. 원본 중복 저장/덮어쓰기는 하지 않는다. 출처 ID를 남기고 새 버전의 파싱 상태는 독립 관리한다.
- SHA-256+크기로 워크스페이스 내 검증된 중복을 조회한다. 새 문서 업로드는 경고 후 별도 문서 등록을 허용하되, 동일 문서의 같은 파일 버전 중복은 차단한다.
- 중앙 미리보기에 버전 타임라인/작성자/시각/메모/출처/현재 버전 표시, 버전별 본문·다운로드·업로드 재시도, 새 버전 업로드 및 수동 연결 UI를 제공한다.
- 같은 문서의 두 버전 메타데이터와 추출 본문을 나란히 비교한다. 자동 text/block diff·AI 요약은 Phase 6으로 남긴다.
- 권한/격리, 동시 번호 할당, 늦은 업로드 완료, 현재 버전 전환, 중복/수동 연결, migration과 기존 기능 회귀를 테스트하고 Docker 개발 서버에 적용한다. 추가 외부 서비스 설정은 없다.
