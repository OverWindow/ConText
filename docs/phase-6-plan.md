# Phase 6 — AI Version Intelligence

1. 정규화된 문서의 블록·단어 차이를 결정적으로 계산하고 출처 블록 ID와 위치를 보존한다. 긴 문서와 변경 목록에는 처리/표시 제한을 알린다.
2. MindlogicProvider → AIService 추상화를 통해 변경 근거만 전송한다. 구조화 결과와 근거 ID를 검증하고 모델·원본 해시·프롬프트 버전을 저장한다.
3. 파일 처리와 분리된 DB outbox/Celery 분석 작업을 추가한다. 중복 요청, 워커 장애, 임대 만료와 오래된 결과 덮어쓰기를 방어한다.
4. 동일 워크스페이스의 현재 READY 버전을 대상으로 SHA-256, 파일명, 텍스트 3-gram, 선택적 의미 임베딩 유사도로 후보를 추천한다. 사용자 선택으로 기존 수동 연결 API를 사용하며 현재 버전은 자동 변경하지 않는다.
5. 비교 화면에 변경 강조·AI 요약, 문서 미리보기에 버전 후보 탭을 추가한다. VIEWER는 조회만 가능하다.
6. 별도 테스트 DB 및 브라우저 fixture로 권한/격리·근거·장애·동시성·모바일을 검증하고 Docker 개발 환경에 적용한다.

실제 환경에 Mindlogic 키가 설정되어 있지 않다. 임베딩 기본값은 text-embedding-3-small이다. 실제 서비스 호출 결과를 꾸며내지 않으며 미설정·실패를 UI와 문서에 명시한다. RAG/pgvector 검색은 Phase 7 범위다.
