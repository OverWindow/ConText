# ConText Desktop

기존 ConText 웹과 별도로 실행하는 Electron 기반 로컬 작업 공간입니다. 웹의 문서 카드와 색상 토큰을 공유합니다. 로그인, Docker, 서버, 인터넷 연결 없이 폴더를 연결하고 탐색할 수 있습니다.

## 실행

저장소 전체가 필요합니다. 공유 UI는 `frontend/shared/ui`, 색상은 `frontend/design`, 브랜드 이미지는 `frontend/public/brand`에서 가져옵니다.

```bash
cd apps/desktop
npm ci
npm run dev
```

Node.js 24 이상을 사용합니다. 최초 Electron 실행과 패키징 때 실행 파일 다운로드가 필요할 수 있습니다. `npm run dev`는 UI를 빌드한 다음 앱을 시작합니다. 코드 수정 후 종료하고 다시 실행하면 반영됩니다. 이미 빌드한 앱은 `npm start`로 실행합니다.

현재 생성한 macOS Apple Silicon 앱:

```text
apps/desktop/release/mac-arm64/ConText Desktop.app
```

Finder에서 해당 앱을 열거나 저장소 루트에서 다음을 실행합니다.

```bash
open "apps/desktop/release/mac-arm64/ConText Desktop.app"
```

서명·공증 전 로컬 개발 빌드입니다. 외부 배포용 서명 인증서나 자동 업데이트는 포함하지 않습니다.

## 사용

1. **폴더 연결**을 눌러 로컬 폴더를 선택합니다. 여러 폴더를 각각 작업 공간으로 연결할 수 있습니다.
2. 파일·이미지·하위 폴더가 기존 문서 카드 형태로 표시됩니다. 폴더를 두 번 누르거나 카드 오른쪽 아래 버튼으로 들어갑니다. 상단 경로로 돌아옵니다.
3. 카드를 드래그해 배치하고 화면을 이동·확대합니다. 폴더별 배치와 화면 위치를 자동 저장합니다. 재실행 후에도 복원됩니다.
4. 파일을 누르면 오른쪽에 메타데이터와 미리보기가 나옵니다. **원본 열기**는 OS 기본 앱으로, **탐색기에서 보기**는 Finder/탐색기로 연결합니다.
5. 상단 검색은 연결한 작업 공간 전체의 **파일 이름**을 검색합니다. 검색 화면은 결과를 격자로 보여 주며 배치를 변경하지 않습니다.
6. 외부 앱에서 파일을 추가·수정·이름 변경·삭제하면 목록을 갱신합니다. OS 감시가 제한되면 주기적 확인으로 전환합니다. 새로고침 버튼도 있습니다.
7. 설정에서 숨김 파일과 개발용 생성 폴더의 내용을 포함할 수 있습니다. 폴더를 옮겼거나 외장 드라이브 경로가 바뀌면 **위치 다시 지정**을 사용합니다.
8. **연결 해제**는 확인 후 앱 내부 목록과 배치만 지웁니다. 원본 파일은 삭제하지 않습니다.

드래그는 캔버스 좌표만 변경합니다. 원본 파일을 이동하거나 복사하지 않습니다. 파일 삭제·편집·새 문서 저장은 현재 데스크톱 범위에 포함하지 않습니다. 기존 웹의 문서 편집/삭제 기능은 웹에서 계속 사용할 수 있습니다.

## 표시 범위와 한계

- PNG/JPEG/WebP/GIF/BMP: 20MB 이하 이미지의 썸네일과 미리보기. OS 디코더가 지원하지 않는 파일은 메타데이터를 표시합니다. 애니메이션은 정지 미리보기입니다.
- TXT/Markdown/CSV/JSON/XML/일부 소스 파일: UTF-8 텍스트의 처음 64KB를 표시합니다. HTML은 실행하지 않고 텍스트로 표시합니다. 다른 문자 인코딩은 깨져 보일 수 있습니다.
- PDF/DOCX/HWP/HWPX 등: 파일 카드·메타데이터·기본 앱으로 열기. 본문 파싱, 내부 편집, 변환은 아직 데스크톱에 연결하지 않았습니다.
- 실행 파일·스크립트는 앱의 **원본 열기**로 실행하지 않습니다. 허용되지 않은 형식은 탐색기에서 확인합니다.
- 심볼릭 링크는 카드로 표시하되 대상 폴더를 따라가거나 내용을 읽지 않습니다.
- 숨김 항목과 `node_modules`, `.git`, `.next`, `.venv`, `__pycache__`의 내용은 기본 제외합니다. 숨김 생성 폴더까지 보려면 두 설정을 함께 켭니다.
- 작업 공간당 최대 25,000개 메타데이터를 수집하며 초과 시 안내합니다. 대규모 폴더는 작은 단위로 연결해 주세요. 화면은 200개씩 추가 표시하고 실제 보이는 노드만 렌더링합니다.
- 파일 감시 후 전체 메타데이터를 다시 확인합니다. 많은 파일이 동시에 변경되는 폴더의 증분 스캔·장시간 부하 검증은 후속 최적화 항목입니다.
- 이름 변경 시 파일 시스템 식별자가 고유하면 배치를 유지합니다. 하드 링크나 다른 볼륨으로의 이동처럼 식별자를 유지할 수 없는 경우에는 경로를 기준으로 복원합니다.
- 로컬 데이터와 파일 내용을 클라우드에 전송하는 기능은 없습니다. 데스크톱 AI·협업·웹 동기화도 아직 없습니다.

## 저장과 구조

Electron `app.getPath('userData')` 아래 `workspace.sqlite`에 연결 폴더, 파일 메타데이터, 카드 좌표, 폴더별 화면 위치를 저장합니다. 원본 내용은 복사하지 않습니다. 이미지 썸네일은 메모리에만 캐시합니다. 드라이브 연결이 끊겨도 캐시된 파일 목록을 보여 줍니다.

```text
src/                     React + React Flow 로컬 화면
  contracts.ts           제한된 preload API 타입
  main.tsx               폴더 선택·캔버스·검색·미리보기
  style.css              데스크톱 레이아웃
electron/
  main.mjs               창·네이티브 대화상자·OS 열기·미리보기
  preload.cjs            허용된 IPC 함수만 노출
  worker.mjs             로컬 엔진 요청과 변경 이벤트
  engine.mjs             SQLite·폴더 스캔·감시·경로 검사
tests/                   파일 엔진 및 실제 Electron 통합 테스트
../../frontend/shared/ui 문서 카드 공통 컴포넌트
```

렌더러는 sandbox/contextIsolation을 켜고 Node 접근을 차단합니다. 외부 페이지 탐색과 새 창을 차단하며, 파일 경로 대신 작업 공간/파일 ID로 요청합니다. 메인 프로세스는 연결 범위와 실제 경로를 확인한 다음 파일을 읽습니다. 폴더 스캔과 SQLite 처리는 Worker에서 실행합니다.

## 검증·패키징

```bash
npm test                 # 파일 감시가 허용된 환경에서 실행
npm run test:e2e          # 실제 Electron 창이 잠시 열림
npm run pack             # 현재 OS용 앱 폴더
npm run dist:mac          # macOS DMG
npm run dist:win          # Windows NSIS (Windows 환경에서 검증 필요)
```

개발 테스트는 `CONTEXT_DESKTOP_DATA_DIR` 환경 변수로 임시 저장 폴더를 지정할 수 있습니다. 패키징된 앱의 별도 프로필은 Electron의 `--user-data-dir=/absolute/path` 인자를 사용합니다.

Windows 설정은 준비되어 있지만 이 macOS 환경에서 Windows 설치·실행을 검증하지 않았습니다. 배포 전에 대상 OS별로 파일 감시, 경로·권한, 한글 이름, 기본 앱 연결과 설치/업데이트를 검증해야 합니다.

최종 패키징된 앱을 대상으로 같은 통합 테스트를 실행하려면:

```bash
CONTEXT_DESKTOP_EXECUTABLE="release/mac-arm64/ConText Desktop.app/Contents/MacOS/ConText Desktop" npx playwright test
```
