# ConText · AI와 함께 쓰는 로컬 문서 작업 공간

대표 문구: **내 문서와 AI가 함께 일하는 공간.**

제품 설명: **내 PC에서 시작하는 AI 문서 작업 공간.** 평소 쓰던 폴더의 자료 탐색, 파일을 근거로 한 AI 질문, 초안 작성과 문서 편집을 한 작업 환경에서 소개한다. 경희대 ChatKHU는 AI 연결 기반으로, 설치·폴더 선택은 간편한 시작 경험으로 설명한다.

랜딩 페이지와 같은 메시지·브랜드 색상으로 구성한 1920×1080 PNG 소스다. 전체 화면 카드 12장, 투명 배경 라벨 6장과 수정 가능한 HTML·생성 코드를 포함한다. 기존 CapCut 프로젝트에서 교체하기 쉽도록 폴더와 이미지 파일명을 유지했다. 파일명이 `same-file` 또는 `apply`인 이미지도 아래의 **현재 내용**을 기준으로 사용한다.

## 내레이션 예시

**오프닝**: “내 문서와 AI가 함께 일하는 공간. ConText는 내 PC에서 시작하는 AI 문서 작업 공간입니다.”

**문제 상황**: “내 자료로 AI와 일하려면 파일을 찾고, 내용을 전달하고, 답변을 다시 문서로 정리하는 과정을 거칩니다.”

**핵심 가치**: “ConText에서는 평소 쓰던 폴더를 바탕으로 자료를 찾고, AI에게 묻고, 문서를 다듬습니다.”

**폴더·검색**: “작업할 폴더를 선택하세요. 익숙한 파일을 열어 보고, 본문 검색으로 필요한 내용을 찾을 수 있습니다.”

**ChatKHU 연결**: “경희대 ChatKHU를 AI 연결 기반으로 활용합니다. 기본 ChatKHU 또는 개인 API 키를 선택하고 사용할 모델을 연결하세요. 개인 키의 사용 크레딧은 해당 ChatKHU 계정에서 차감됩니다.”

**질문·근거**: “내 자료에 대해 질문하고, 답변에서 근거가 된 파일도 함께 확인합니다.”

**문서 작성**: “회의록을 바탕으로 업무 보고서 초안을 만들거나, 메모를 체크리스트로 정리해 보세요. 초안의 문장을 AI와 함께 다듬을 수 있습니다.”

**수정안 확인**: “초안에서 수정 전후를 비교하고, 원하는 변경만 선택해 적용합니다.”

**파일에서 계속**: “TXT와 Markdown은 텍스트 편집에서 원본에 직접 저장할 수 있습니다. 다른 문서는 내용을 새 초안으로 가져와 편집하고, 별도 파일로 내보냅니다.”

**로컬 환경**: “파일 작업과 기록은 내 PC에서 관리합니다. AI 답변과 초안 생성에는 인터넷과 AI 연결이 필요하고, 필요한 발췌문이 연결한 서비스로 전송됩니다. 클라우드 동기화는 필요할 때 선택하세요.”

**엔딩**: “자료를 찾고, AI에게 묻고, 문서를 다듬으세요. 내 문서와 AI가 함께 일하는 공간. ConText.”

## 현재 기능과 시연 범위

기준: `docs/product-direction.md`와 현재 소개 페이지, 2026-10-28.

- 카드는 설명용 합성 그래픽이다. 실제 앱 화면이나 실시간 AI 응답으로 소개하지 않는다. 관련 표시는 자르지 않는다.
- 로컬 파일 검색·AI 답변과 인용·자료 기반 초안 작성·초안의 AI 수정안 비교와 적용·TXT/Markdown 직접 편집을 현재 기능으로 설명한다.
- 06–09의 결과는 **새 초안 또는 초안 수정안**이다. 원본 파일을 AI가 자동 수정한 결과로 보여주지 않는다.
- 10은 TXT·Markdown을 사용자가 직접 편집해 저장하는 예시다. DOCX·HWPX·PDF 등의 원본을 직접 덮어쓰는 기능을 뜻하지 않는다.
- 채팅 → 수정안 비교 → 같은 원본 파일에 바로 적용하는 통합 흐름은 후속 개발이다. 이번 개편의 메인 카드에서는 이 흐름을 현재 기능처럼 시연하지 않는다.
- 랜딩의 원본 적용 프리뷰는 개발 방향을 보여주는 상호작용 예시다. 영상의 현재 기능 시연과 혼동하지 않는다.
- 로컬은 파일 작업·기록 보관의 위치다. AI가 내 PC에서 완전 오프라인으로 실행된다는 뜻이 아니다.

## CapCut 사용·교체

16:9 프로젝트에 `png/` 이미지를 가져온다. 01–12는 기본 트랙에, 13–18은 실제 녹화 위쪽 트랙에 넣는다. 라벨은 왼쪽 아래, 하단에서 150px 위에 배치되어 있다. 확인할 UI와 겹치면 위치를 조절한다. 투명 라벨은 배경 제거가 필요 없다.

기존 소스를 이미 가져왔다면 같은 번호의 새 PNG로 미디어를 교체한다. CapCut에 이전 이미지가 계속 보이면 새 PNG를 다시 가져와 교체한다. 특히 03·06–10·15–17은 전달 내용이 바뀌었으므로 위 구성에 맞춰 장면과 기존 내레이션·자막을 함께 바꾼다.

전체 화면 카드는 0.2–0.3초 디졸브, 라벨은 0.2초 페이드 인·아웃을 권장한다. 이 묶음에는 정적 PNG·수정 가능한 HTML·생성 코드·구성안이 포함된다. 음성·실제 화면 녹화·완성 MP4·CapCut 프로젝트 파일은 포함하지 않는다.

## 재생성

저장소 루트에서 실행한다. 프론트엔드 의존성과 Chrome이 필요하다.

```bash
node artifacts/context-capcut-local-chatbot-2026-10-28/render.mjs
```

`scenes.mjs`에서 카드·라벨 문구를 수정한다. `render.mjs`는 PNG 18장과 HTML, 미리보기 3종, 해시·규격·레이아웃 검사 결과를 담은 `manifest.json`을 생성한다. 재생성 후 미리보기를 확인하고 시각 검토 결과를 기록한다.
