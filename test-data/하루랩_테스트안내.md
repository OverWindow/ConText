# 하루랩 스타트업 샘플 테스트 안내

이 자료는 가상의 6인 스타트업 하루랩이 카페 발주·재고 서비스 모아오더를 준비하는 상황입니다. 회사, 인물, 고객, 이메일, 실적과 예산은 모두 가상이며 기준일은 2026-10-24입니다.

## 바로 시작하기
ConText Desktop에서 **폴더 연결**을 누르고 `하루랩_스타트업_샘플` 폴더를 선택합니다. ZIP은 풀어서 연결합니다. 상위 `test-data` 폴더를 연결하면 답안·안내까지 섞이므로 샘플 폴더만 선택해 주세요.

## 폴더 구성
- 01_회사소개: 회사와 팀, 한 페이지 회사소개 PDF
- 02_제품기획: 요구사항, API 명세, 출시 체크리스트, 웹·모바일 화면 PNG
- 03_회의록: 우선순위와 요금제 결정, 출시 점검
- 04_고객영업: 가상 고객 12곳, 피드백 8건, 인터뷰, DOCX·PDF 제안서, 이메일 원문
- 05_운영재무: 수식이 있는 예산 XLSX, 주간 보고 DOCX·HWPX, 지출계획 CSV
- 06_개발운영: 장애 기록, 릴리스 노트, 지표 JSON, 제품 구조 PNG
- 07_브랜드마케팅: 브랜드 가이드, 로고 SVG, 출시 공지 초안
- 90_이전자료: 현재 정책과 다른 폐기 가격·일정·범위
- 99_기능테스트: 빈 파일·빈 폴더·긴 한글 이름·다국어·공백·숨김 파일

## 현재 데스크톱에서 시험할 항목
1. 폴더를 연결해 아홉 개 업무·보관 폴더와 자료 안내 파일이 나오는지 확인합니다.
2. `02_제품기획`으로 들어가 화면설계 PNG 두 개가 썸네일로 나오는지 확인합니다. 이미지를 누르면 크게 보입니다.
3. 상단 검색에 `화면설계`를 입력하면 두 파일이 나옵니다. `회의록.md`를 검색하면 서로 다른 폴더의 동명 파일 두 개를 구분할 수 있습니다. 검색은 파일 이름을 대상으로 합니다.
4. `요금제확정`을 검색해 Markdown을 열고 99,000원·5명·14일·11월 6일을 읽습니다. 본문 단어만으로 검색하는 전문 검색은 아직 데스크톱에 없습니다.
5. `99_기능테스트`에서 빈 파일의 크기가 0 B인지, 빈 폴더에 들어갔을 때 빈 상태가 뜨는지 확인합니다.
6. 긴 한글 이름과 `한글_日本語_English.txt`가 깨지지 않는지 확인합니다.
7. 설정에서 숨김 파일을 켜면 `.숨김메타.json`이 추가되고, 끄면 사라지는지 확인합니다. 기본 상태 파일 38개, 숨김 포함 39개입니다. 운영체제가 추가하는 .DS_Store 같은 메타데이터는 이 수에서 제외합니다. 폴더 카드는 파일 수와 별도입니다.
8. 카드 2~3개를 이동하고 확대 비율을 바꾼 후 앱을 완전히 종료했다 다시 엽니다. 배치와 화면이 복원되는지 확인합니다.
9. `99_기능테스트`에 직접 메모를 추가하고 내용 수정·이름 변경·삭제를 해 보며 목록이 갱신되는지 확인합니다. 원본 샘플 복구는 제공한 ZIP을 다시 풀면 됩니다.
10. DOCX·PDF·HWPX·XLSX는 카드와 메타데이터가 보입니다. **원본 열기**는 해당 형식을 지원하는 OS 앱이 있어야 동작합니다. 이 데스크톱 버전에는 이들 형식의 본문 파싱·편집이 아직 연결되지 않았습니다. SVG와 EML도 메타데이터 표시용이며 PNG 썸네일처럼 렌더링되지 않습니다.

## AI 문서 작성 연결 후 사용할 요청
현재 데스크톱의 AI 기능을 뜻하는 것이 아니라 후속 구현 검증용입니다. 웹에서는 지원 형식의 문서를 업로드해 사용할 수 있습니다. 회사 자료가 없는 질문은 추측하지 않는지도 확인합니다.

- 현재 자료를 찾아 다음 주 출시 준비 보고서를 작성해 줘. 담당자와 마감일을 붙여 줘.
- 샘플카페09 문의를 참고해 최신 가격과 범위로 도입 제안서를 써 줘.
- 이전 계획에서 요금과 출시일이 왜 달라졌는지 결정 근거를 찾아 줘.
- 고객 불편에서 이번 출시 우선순위로 이어진 근거를 정리해 줘.
- 운영 예산에서 10월 말 예상 현금과 런웨이를 설명해 줘.

`하루랩_테스트정답.json`에는 10개 요청의 기대 답과 근거 파일이 있습니다. 최신 문서 우선, 확정 현황과 목표의 구분, 자료에 없는 사실을 지어내지 않는지를 평가합니다. 이 답안은 자료 폴더 밖에 유지하고 AI 입력에 포함하지 마세요.

## 예산표 사용
노란색 구독료 또는 11·12월 유료 매장 수를 바꾸면 MRR과 현금흐름이 계산됩니다. 원래 조건은 99,000원, 11월 20곳, 12월 35곳입니다. 11월 고객을 1곳 늘리면 같은 달 현금 수입과 11·12월 말 잔액이 99,000원씩 증가해야 합니다.

고객목록 시트는 가상 원천 자료이고 현금흐름 시트는 가상 전망입니다. 월초 가입·당월 전액 수금, 세금·투자·차입·설비투자 제외를 가정했습니다. 회계 보고용 자료가 아닙니다.

## 검증 범위
DOCX와 PDF는 렌더링해 한글·표·페이지 배치를 확인합니다. XLSX는 수식 재계산과 입력 변화 결과를 확인합니다. HWPX는 python-hwpx 6.8.0의 스키마와 ZIP/XML 본문 검증을 통과했습니다. 한컴 원본 앱에서의 레이아웃은 별도로 확인해야 합니다.

실제 패키징된 ConText Desktop의 임시 프로필로 폴더 연결, 하위 목록, 숨김 기본 제외, 빈 파일, HWPX/XLSX 표시, 전체 이름 검색, PNG 썸네일·미리보기, 한글 Markdown 미리보기를 확인했습니다. Docker 서비스는 시작하지 않았습니다.
