# 모아오더 출시 안내 초안
2026-10-23 | 김태오 | 검토 중 | 가상 자료

모아오더가 2026년 11월 6일 정식 출시를 준비합니다. 품목별 단위와 발주 목록을 한곳에서 관리하고, 입고 수량을 확인할 수 있습니다. 시범 매장 12곳의 의견을 바탕으로 초기 설정과 재시도 안내를 개선하고 있습니다.

스탠더드 요금은 매장당 월 99,000원이며 부가세 별도입니다. 14일 무료 시범 후 유료 전환 여부를 직접 선택합니다. 구성원 5명이 함께 사용할 수 있고 초기 원격 설정을 1회 지원합니다.

출시 전 확인: 정하린의 11월 5일 승인, 최신 화면 이미지, 문의 창구 연결을 확인한 뒤 게시합니다. 현재 초안은 외부 게시 승인 전입니다.
