# 제품 우선순위·요금제·출시 점검 요약

제공된 자료는 제품 범위와 출시 준비, 요금제 및 출시일 결정을 다룹니다\. 공통적으로 정식 출시를 준비하면서 품목 단위 입력과 발주 중복 제출 방지를 중요하게 다루지만, 문서별로 결정의 확정도와 초점은 다릅니다\.

## 제품 범위와 우선순위

10월 16일 우선순위 회의에서는 품목별 단위와 초안 복원을 정식 출시 필수 범위로 정했습니다\. POS 연동은 공급사 API 조건을 확인하지 못해 다음 분기로 미루고, 기능 수를 늘리는 것보다 발주 중복 제출을 막는 일을 우선하기로 했습니다\.

## 확정된 요금제와 일정

10월 21일 승인 회의에서 스탠더드 요금은 매장당 월 99,000원, 구성원 5명 포함, 부가세 별도로 확정됐습니다\. 무료 시범은 14일이며 자동 유료 전환은 없고, 초기 설정은 원격으로 1회 지원합니다\. 정식 출시일은 2026년 11월 6일로 변경됐으며, 10월 30일 출시 계획과 월 79,000원 가격 초안은 폐기해 이전 자료에 폐기 상태를 표시해 보관하기로 했습니다\.

## 제품팀 상시 메모

10월 22일 메모는 공식 확정 문서가 아니라고 명시합니다\. 메모에는 단위 선택 드롭다운에 박스와 낱개를 함께 표시하고, 품목을 바꿀 때 이전 단위가 남지 않도록 확인하자는 내용이 담겨 있습니다\.

## 출시 점검과 남은 위험

10월 23일 점검에서는 11월 6일 출시일을 유지했지만, 단위 입력과 재시도 처리는 진행 중이라고 기록했습니다\. 10월 30일 모바일 QA 이후 최종 범위를 다시 확인할 예정이며, 저장 응답이 늦을 때 사용자가 제출을 반복하는 문제는 서지우가 요청 키 검증을 10월 29일까지 완료하기로 했습니다\.
