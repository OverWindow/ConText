# 하루랩 내부 공유 자료

이 폴더는 ConText 기능 시험을 위해 만든 가상 스타트업 자료입니다. 회사, 인물, 고객, 실적, 일정, 이메일은 모두 가상입니다. 기준일은 2026년 10월 24일입니다.

하루랩은 6명이 카페 발주·재고 관리 서비스 모아오더를 만드는 팀입니다. 시범 매장 12곳 중 8곳이 유료이며, 정식 출시 목표일은 2026년 11월 6일입니다.

## 자료를 읽는 순서
1. 회사소개에서 팀과 사업 현황을 확인합니다.
2. 제품기획과 최근 회의록에서 확정한 범위를 읽습니다.
3. 고객영업에서 실제 요구사항과 제안 내용을 비교합니다.
4. 운영재무에서 예산 가정과 업무 담당자를 확인합니다.

최신 요금제는 2026-10-21 회의록과 제품요구사항 v1.2를 기준으로 합니다. 90_이전자료는 폐기·구버전 표시가 있는 기록입니다. 이전 결정을 현재 정책으로 사용하지 마세요.

이번 자료 묶음에 포함된 이미지는 가상 제품의 화면 설계와 구조도입니다. 실제 서비스 화면을 캡처한 자료가 아닙니다. XLSX 수치는 가상 전망이며 실제 회계자료가 아닙니다.
