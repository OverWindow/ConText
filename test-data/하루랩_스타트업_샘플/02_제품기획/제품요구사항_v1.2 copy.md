# 모아오더 제품요구사항 v1.2
상태 승인 | 2026-10-23 | 제품 책임 정하린 | 가상 자료
이 문서는 v1.0을 대체합니다. 정식 출시일은 2026-11-06입니다.

## 목적과 성공 기준
첫 매장의 품목 20개를 등록하고 첫 발주 목록을 만들기까지 15분 이내가 목표입니다. 11월 말까지 유료 20곳을 확보하고 중복 발주 접수는 0건을 유지합니다. 목표값과 현재 측정값을 구분합니다.

## 요금과 지원
스탠더드 1개 요금제만 운영합니다. 매장당 월 99,000원, 매장 구성원 5명 포함, 부가세 별도입니다. 무료 시범 기간은 14일입니다. 시범 기간이 지나도 자동 결제하지 않으며 유료 전환 동의를 받습니다. 가입 초기 설정은 1회 원격 지원합니다.

## 제외 범위
POS 자동 연동, AI 자동 발주, 공급사 자동 주문 전송, 다점포 통합 정산은 이번 출시에서 제외합니다. 발주 목록을 만드는 것과 실제 공급사에 주문이 전달되는 것은 별도 단계입니다.

## 오류와 경계 조건
수량 0은 임시저장할 수 있지만 제출할 수 없습니다. 음수는 저장 전에 막습니다. 오프라인이면 초안만 저장하고 제출 버튼에 연결 필요를 표시합니다. 동일 요청 키 재시도는 새 발주를 만들지 않습니다.
