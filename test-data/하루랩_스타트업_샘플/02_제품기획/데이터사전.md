# 모아오더 데이터 사전
2026-10-23 | 가상 자료

customer_id는 계약 매장 식별자입니다. 하나의 고객 레코드는 한 매장으로 정의합니다. 이번 묶음에서 C001~C012는 서로 다른 매장입니다.
status의 paid는 유료 사용 중, pilot은 14일 무료 시범을 뜻합니다. paid만 MRR에 포함합니다. 종료한 매장은 이번 고객 목록에 없습니다.
monthly_fee_krw는 부가세 제외 월 정가입니다. 무료 시범은 0원이며, 매출 합계와 유료 매장 수에 포함하지 않습니다.
orders_7d는 2026-10-17~2026-10-23 기간의 제출한 발주 목록 수입니다. 공급사 주문 성공 건수나 판매 매출이 아닙니다.
feedback_id와 customer_id를 연결하면 고객 요청과 영업 후속 조치를 묶어 볼 수 있습니다.

현금흐름 파일은 가상 전망 모델입니다. 예측 고객이 월초부터 사용하고 구독 대금을 같은 달 모두 수금한다고 단순화했습니다. 투자금, 차입금, 설비 투자, 부가세와 법인세는 제외합니다. 실제 회계 보고에 사용할 수 없습니다.
